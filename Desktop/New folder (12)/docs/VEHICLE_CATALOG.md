# کاتالوگ خودرو — قرارداد فاز ۲

کاتالوگ خودرو داده مرجع است و به Organization/Store scope نمی‌شود؛ داده‌های تجاری آینده باید tenant-scoped بمانند. `VehicleVariant` دقیق‌ترین سطح قابل اتصال به Fitment است و با نسل، موتور و گیربکس ارتباط دارد.

اطلاعات منبع در `vehicle_data_sources` و `vehicle_variant_sources` نگه‌داری می‌شود. `VERIFIED` فقط برای مدرکی نمایش داده می‌شود که اپراتور مجاز آن را بررسی کرده باشد؛ داده `UNVERIFIED` حقیقت قطعی نیست.

وابستگی‌های فاز ۳: Fitment باید به `vehicle_variant_id` متصل بماند، محدودیت‌های موتور/گیربکس را از همین رابطه بخواند و از استنتاج سازگاری بین نسل‌ها خودداری کند.
