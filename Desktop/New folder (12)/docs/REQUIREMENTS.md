# نیازمندی‌ها

## الزامات غیرقابل مذاکره

- SKU، OEM و شماره سازنده مستقل هستند.
- TechnicalPart از Product جدا است.
- Fitment بدون Evidence معتبر VERIFIED نیست.
- گردش قطعی موجودی و سند مالی حذف/ویرایش مستقیم نمی‌شود.
- داده تجاری با organization/store scope جدا می‌شود.

## محدوده Phase 1

ورود کاربر، نقش‌ها و مجوزهای پایه، داشبورد RTL، جداول tenancy و کاتالوگ اولیه خودرو/قطعه.
