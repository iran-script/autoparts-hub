# مدل دامنه

VehicleVariant نسخه دقیق خودرو است؛ Engine و Transmission محدودیت فنی را مدل می‌کنند. TechnicalPart تعریف فنی مستقل از برند است و Product کالای فیزیکی با SKU/بارکد/برند مستقل.

Fitment یک ادعای سازگاری است؛ Evidence منبع و بازبینی آن را ثبت می‌کند. وضعیت‌ها: VERIFIED، SUPPLIER_CLAIMED، UNVERIFIED، CONFLICTED، REJECTED.
